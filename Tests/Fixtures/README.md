# Проверка состояния целевого окна

`./Tests/Fixtures/build.sh` собирает отдельное тестовое приложение в `.build/WindowZonesLifecycleProbe.app`, SDK 27.0, минимум macOS 15, arm64. Оно не устанавливается в Applications и не читает чужие окна. Приложение WindowZones устанавливать только через `./scripts/install.sh --diagnostics`.

1. Открыть тестовое приложение. В диагностике WindowZones обновить список и выбрать WindowZones Lifecycle Probe.
2. В тестовом окне нажать Close in 8 seconds или Minimize in 8 seconds.
3. До истечения задержки открыть выбор зон из диагностики. Убедиться, что панель уже видима и цель указана правильно.
4. Не нажимать на зоны или за пределами панели. После отложенного закрытия/сворачивания панель и preview должны исчезнуть без snap. Диагностика должна сообщить причину отмены.
5. Снова открыть тестовое приложение для следующего сценария. Оно восстанавливает своё единственное окно при reopen.
6. После проверки завершить тестовое приложение. Пользовательские окна и документы не закрывать.

Отдельно проверить, что живая цель не закрывает picker самопроизвольно, Escape отменяет, а размещение и Undo продолжают работать. Проверка этой fixture не заменяет реальные fullscreen, отзыв Accessibility, Space/sleep и физический drag.
