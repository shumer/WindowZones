# 08. Полноценный редактор

Статус: Очередь.
Зависимости: 02, 05, 06.

[Очередь задач](README.md) · [Спецификация](../Specification.md)

## Результат

Реализовать отдельное окно редактирования дерева зон, а не только ползунок центра из макета.

## Работа

- [ ] Выбор leaf, vertical/horizontal split, перемещение разделителя и точный ввод.
- [ ] Именование, дублирование, удаление с отменой; защита последней раскладки.
- [ ] Draft, Save, Cancel, явное решение при закрытии с изменениями.
- [ ] Ошибки слишком маленьких зон и лимитов показываются рядом с действием.

## Проверки и условие завершения

- [ ] Все операции работают мышью и клавиатурой; сохраняется валидное дерево.
- [ ] Cancel и закрытие не теряют сохранённую версию, редактор не двигает окна.
- [ ] Проверены en/ru длины подписей до финальной локализации.

## Границы

Без свободных перекрывающихся зон.

## Журнал и следующий шаг

Не начато.
