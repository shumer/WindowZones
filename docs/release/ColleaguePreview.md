- Исходный коммит c5985308f4caf0cf17020de56a42db6495448844. Checks 37611605806 и Signed release candidate 37612013134 успешны.
- 60 тестов прошли. CI SDK 26.5, локальная разработка SDK 27.0, минимум macOS 15, arm64.
- Apple notarization Accepted, ticket da89d21a-1588-429a-8f95-c0fe348aea16. Проверены SHA-256, codesign, staple, Gatekeeper и EdDSA архива против публичного ключа установленной 0.1.0.
- Точный архив CI установлен через install.sh --release-app поверх опубликованной 0.1.0. Accessibility сохранился, SHA-256 layouts.json не изменился. В Applications оставлена 0.2.0, бинарник совпадает с архивом.

Процесс продолжал работать, sample показал обычное ожидание событий, но это не доказательство успешного snap. Предыдущие проверки локального кода и подтверждение Slack пользователем сохраняются как отдельные результаты.
- Публичный latest API и HTTPS appcast после публикации проверены: 0.2.0, build 2, ссылка на архив v0.2.0.

Далее собрать обратную связь коллег, проверить указанные пробелы и исправлять воспроизводимые дефекты. Полный roadmap не считается завершённым.


Оценка на 7 октября 2026: можно готовить ограниченную тестовую раздачу 3-5 коллегам. Полный roadmap и общая приёмка совместимости не завершены. Не заявлять стабильную версию для всех приложений и мониторов.

## Что входит

- Пять стандартных раскладок, верхняя полоска при переносе, Shift-drag и выбор с клавиатуры.
- Размещение и Undo. Серии Finder, Safari и Slack зафиксированы в Stage0Results, но не являются полной регрессией текущей сборки.
- Помощник заполнения свободной зоны с карточками и восстановлением свёрнутого окна по выбору.
- Базовые настройки, автозапуск, Sparkle, Developer ID и GitHub pipeline с notarization.
- Пользователь подтвердил исправленный перенос Slack 7 октября.

Последние локальные тесты: 60. В GitHub опубликован только 0.1.0. Последний успешный Checks относится к 53822a5, а не к текущим локальным изменениям. Установленная локальная подпись не заменяет notarization следующего артефакта.

## Перед раздачей

1. Обновить пользовательские release notes и README под фактический интерфейс, перечислить ограничения.
2. Отправить зафиксированный кандидат в GitHub и получить успешный Checks именно на его коммите.
3. Выбрать новую версию и больший build number. Собрать подписанный и нотарифицированный draft штатным workflow.
4. Проверить именно этот архив: первый запуск на другом Mac, Accessibility, разрешение миниатюр, размещение, Undo, повторный запуск. Проверить обновление с 0.1.0 и сохранение настроек.
5. Для ограниченного круга использовать GitHub prerelease и прямую ссылку после отдельного поручения на публикацию. Текущий Sparkle feed использует releases/latest и не доставляет prerelease обычным пользователям автоматически.

Предложение версии: 0.2.0 как prerelease. Версия и tag пока не созданы, публикация не выполнялась. Workflow принимает tag вида vX.Y.Z; признак prerelease задаётся выпуску GitHub.

## Ограничения тестовой версии

- Артефакт arm64, минимум macOS 15. Основная проверенная среда сейчас macOS 27.0.1, совместимость всего диапазона не доказана.
- Быстрый старт drag, fullscreen, Spaces, сон, отключение монитора и отзыв разрешений не прошли полную матрицу.
- Chrome ранее давал пустой AX-список; последующие миниатюры Chrome не доказывают исправление управления его окнами.
- Telegram среди свёрнутых окон отдельно не проверен. AX-сканирование имеет общий бюджет 3 секунды.
- Минимальный размер некоторых окон больше зоны. Undo после восстановления из Dock возвращает геометрию, но не сворачивает окно обратно.
- Редактор раскладок, полные профили, исключения, локализация и расширенная доступность остаются в плане.
