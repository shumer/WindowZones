# Очередь задач WindowZones

Последовательный план после выпуска: [NextSteps.md](../NextSteps.md).
Актуальный снимок для продолжения: [CurrentState.md](../CurrentState.md). Прочитать первым, исторические записи ниже могут описывать предыдущую сборку.

Это текущая точка входа. Пользователь 19 сентября 2026 согласовал движение по предложенному плану и поручил начать работу. Основное направление: A (панель) + C (Shift-drag). B (кнопка около окна) не блокирует первую версию.

02 и 03 можно вести параллельно: UX-сессии не требуют изменения работающего AX-прототипа. Без доступных участников 02 остаётся непроведённой, это не блокирует техническую работу по 03-05. Изменить условия перехода к 06 можно только явным решением с записью причины.

После поручения пользователя продолжать доступную работу при заблокированном Accessibility разрешена независимая реализация чистого ядра 04 и его последующего хранения 05. Они не меняют реальное управление окнами. Подключение в приложение и задача 06 сохраняют зависимости от реальной проверки 03 и UX 02. Этап 0 не считается закрытым.

## Как продолжать

1. Прочитать AGENTS.md, Specification.md и карточку первой незавершённой доступной задачи.
2. Проверить фактическое состояние кода и журнал, не повторять уже сделанное.
3. Выполнить ограниченный объём карточки и подходящие проверки.
4. Записать файлы, результат, ограничения и следующий шаг в карточку. Обновить эту таблицу.
5. При привлечении субагентов назначать разные области записи. Ревью может быть read-only. Не давать нескольким агентам менять App.swift одновременно.

Не нужно заранее создавать отдельные задачи в интерфейсе приложения. Этот список является файловой очередью; карточки можно использовать как задания по одной.

## Текущая передача

По заданию пользователя опубликован ранний выпуск 0.1.0: https://github.com/shumer/WindowZones/releases/tag/v0.1.0. Иконка, базовые настройки, Sparkle и GitHub CI с подписью и notarization готовы. Проверены 45 тестов, подписанный артефакт, настройки и полный upgrade тестовой копии 0.0.0 до опубликованной 0.1.0. Приложение установлено в Applications. Остались ручной Accessibility для постоянного bundle ID, проверка настоящего login и расширенная матрица совместимости. [CurrentState.md](../CurrentState.md) содержит точное продолжение.

Ранний выпуск не закрывает полную приёмку03/06/07/12. Верхняя полоска подтверждена пользователем одним drag, Finder Retina ранее прошёл10 snap/undo exact.
