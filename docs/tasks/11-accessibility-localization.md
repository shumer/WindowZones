## Результат

Довести все пользовательские поверхности до доступного нативного поведения.

## Работа

- [ ] Системные цвета/материалы с availability для macOS 15+, светлая/тёмная темы.
- [ ] VoiceOver имена/состояния, логичный focus, все операции с клавиатуры.
- [ ] Reduce Motion, Increase Contrast, Reduce Transparency, выбор не только цветом.
- [ ] en/ru строки, длинные подписи, локальные числа и сообщения ошибок.

## Проверки и условие завершения

- [ ] Реальная проверка VoiceOver, keyboard-only и системных режимов.
- [ ] Нет потерянных действий, обрезанных обязательных подписей и новых API без fallback.
