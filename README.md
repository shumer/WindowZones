# WindowZones

Нативная утилита macOS с пользовательскими зонами для окон. Рабочее имя, не выбранный бренд.

Готовится ранний выпуск 0.1.0 для Apple silicon. Минимальная система macOS 15, реальные проверки пока проводились на macOS 26.6.2 и 27.0.

Есть верхняя полоска раскладок при перетаскивании, четыре встроенные раскладки, Shift-drag, панель по Control+Option+Space и Undo. Настройки включают автозапуск по желанию пользователя и подписанные обновления Sparkle. Редактор собственных раскладок ещё не реализован.

[Сборка и выпуск](docs/release/README.md) · [Известные ограничения](docs/release/ReleaseNotes.md) · [Текущее состояние](docs/CurrentState.md).

## Запустить прототип

```sh
./scripts/test.sh
./scripts/build.sh
open build/WindowZones.app
```

Нужны macOS 15+ и установленный toolchain Swift 6.4 с macOS SDK 27.0. Проверяется локальная arm64-сборка, другие ОС и Intel пока untested. Сторонних зависимостей нет.

В приложении открыть Accessibility и вручную выдать доступ `build/WindowZones.app`. Затем активировать обычное чужое окно, нажать Control+Option+Space и выбрать 1, 2 или 3. Undo находится в меню. Shift-drag включается отдельно как эксперимент. На запуске чужие окна не перемещаются.

[Сценарий проверки и подробности сборки](docs/Stage0Results.md).

## С чего начать

1. Прочитать [спецификацию](docs/Specification.md).
2. Открыть [очередь задач](docs/tasks/README.md) и первую незавершённую доступную карточку.
3. Выполнить её объём и проверки, обновить журнал и статус. Сейчас в работе задача 03: завершение надёжности этапа 0.

Пользователь согласовал направление: аналог FancyZones с кастомными зонами, пригодный для других пользователей, разработка по шагам. Детали спецификации пока являются рабочими предложениями, а не отдельно утверждёнными решениями.

## Решения, которые можно отложить

Название, иконка, публичность исходников, цена, лицензия, сайт, домен и Apple Developer account нужны ближе к распространению. Они не блокируют проверку перемещения окон.

До расширенной проверки нужны реальные версия macOS, конфигурация мониторов и 5-8 приложений пользователя. Агент может начать подготовку и unit tests без этих ответов; проверки на недоступном оборудовании помечает как непроведённые.
