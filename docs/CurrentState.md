## Выпуск 0.1.0 опубликован

Релиз: https://github.com/shumer/WindowZones/releases/tag/v0.1.0. Tag v0.1.0 закреплён за 36bbe6f, после публикации не перемещать. Пользователь явно поручил ранний выпуск перед дальнейшими улучшениями; это не закрывает всю матрицу AX/drag.

Реализованы иконка с воспроизводимым генератором, базовые AppKit-настройки, opt-in автозапуск через SMAppService.mainApp, ручные и автоматические проверки Sparkle 2.10.0. Постоянный bundle ID: com.shumer.WindowZones. Feed: https://github.com/shumer/WindowZones/releases/latest/download/appcast.xml.

GitHub environment release настроен. После исправления NOTARY_ISSUER_ID workflow 35454801082 успешно подписал, нотарифицировал и упаковал приложение. Ключ Sparkle хранится в локальном Keychain account com.shumer.WindowZones и release secret; не менять его для обычных обновлений. Лицензия Sparkle включена в приложение.

Проверено:

- 45 unit tests, локальные сборка и smoke. Локальный SDK 27.0, CI Xcode 26.6 / SDK 26.5. Минимум macOS 15, только arm64.
- У скачанного артефакта проверены SHA256, Developer ID, hardened runtime, stapled notarization и Gatekeeper: Notarized Developer ID.
- Подпись архива EdDSA проверена независимо, публичный appcast соответствует артефакту.
- Настройки и иконка осмотрены на реальном Mac. Ручная проверка Sparkle сообщает, что 0.1.0 актуальна.
- Изолированная тестовая копия с версией 0.0.0 скачала опубликованную 0.1.0 через Sparkle, установила её и перезапустилась. Версия, подпись и notarization после обновления проверены; executable совпадает с опубликованным.
- Опубликованное приложение установлено в /Applications/WindowZones.app и запущено. Автозапуск и автоматическая проверка выключены.

Не проверены регистрация автозапуска и настоящий новый вход в систему, установка на чистом профиле, повреждённое обновление и полный uninstall. На момент публикации Accessibility для постоянного bundle ID ещё не был выдан; в октябрьских проверках ниже он разрешён. Тестовые копии остановлены. Релиз ранний, с известными ограничениями drag и совместимости.

## Продолжение 6 октября: drag и 50/50

Локальная правка разделяет captureDragCandidate и validateDragCandidate. Порог движения курсора 3 pt проверяется сразу после чтения исходной геометрии, до capability checks. Движение во время последующей валидации больше не отменяет уже зафиксированный baseline. После валидации checkDrag вызывается сразу. Проверки заголовка, settable, fullscreen, minimized, cancellation и движения окна сохранены. Живой эффект быстрого drag ещё не измерен.

На установленной 0.1.0, macOS 27.0.1 (26A434), Accessibility разрешён. Finder в левой и правой половинах показал adjusted с недостающей высотой 11 и 7 pt. Undo exact. Повторная команда в правую половину дала точный размер 1268x1304. Это новое воспроизведение, не опровержение сентябрьской проверки на другом экране. Полные frames: Stage0Results.md.

Кандидат добавляет один size retry после основной коррекции frame, если размер остался неточным, и при необходимости последнюю коррекцию позиции. AX budget 1400 ms, общий предел с восстановлением 2000 ms. Повтор не зацикливается на ограничениях приложения.

45 unit tests прошли после обеих правок. Release собран SDK 27.0 и подписан Developer ID, подпись проверена. Установленная копия завершена, тестовая build/WindowZones.app запущена через Finder; процесс подтверждён. Диагностика кандидата открыта пользователем, Accessibility сохранился. Четыре размещения Finder exact, но переход на Retina выявил оставшуюся ошибку ширины 3 pt. Условие retry уточнено, release и подпись снова прошли, 45 тестов повторно прошли. Новый живой прогон впереди. После пересборки прежний тестовый процесс уже отсутствовал, запуск через CUA вернул timeout. Пользователю отправлен запрос открыть build/WindowZones.app и диагностику. Chrome capture дважды вернул AX -25212, пара приложений ещё не проверена. 7 октября пользователь разрешил замену Applications. Кандидат установлен через Finder и запущен с --diagnostics без участия пользователя. Accessibility сохранился. Релиз GitHub не менялся; резервная копия .build/backups/WindowZones-0.1.0.app.

## Актуальное состояние после повторной установки 7 октября

Локальные изменения сохранены отдельными коммитами: b4e9ed6 (drag capture, ограниченная коррекция размера, самостоятельная диагностика) и 5a73308 (повторяемая подписанная установка). Устанавливать только через ./scripts/install.sh --diagnostics, как предписано AGENTS.md. Две установки подряд прошли, Accessibility сохранился и проверен реальными командами Finder. Пользователь не должен повторно открывать диагностику после обычной установки.

Контрольные snap/Undo Finder на основном экране и один цикл основной экран/Retina дали exact во всех четырёх операциях. Frames и время записаны в Stage0Results.md. Это не закрывает перемежающийся AX -25204, неточный rollback или эффективность settled size retry. Окно восстановлено в правую половину основного экрана.

Ближайший шаг: диагностика конкретной AX-операции при ошибке и проверка rollback после частичного межэкранного переноса. В текущем rollback размер восстанавливается до позиции, возможное ограничение меньшим экраном требует воспроизведения. Затем пара Finder/Chrome, быстрый drag и негативные сценарии карточки 03. Редактор пока не начинаем. Новый релиз не создан.


## Исправление восстановления после ошибки, 7 октября

На реальном Finder с контролируемым сбоем после переноса подтверждена причина неполного rollback: прежний код увеличивал окно ещё на Retina, где высота ограничивалась 941 pt, и затем возвращал его на основной экран без повторного увеличения. Новый порядок вернул исходные 1284/38/1268/1304 полностью. Временный тестовый сбой удалён из исходников.

Ошибки теперь содержат этап и конкретный AX-вызов, восстановление имеет отдельные samples. Неподтверждённый actual больше не заполняется старым frame. Общий предел 2 s не изменён. Исходный перемежающийся AX -25204 остаётся открытым: исправлено его возможное последствие, а не доказана причина. Следующие проверки карточки 03: поздний timeout и отмена восстановления, обратный перенос, пара приложений и drag.


Итоговая обычная сборка установлена через install.sh, подпись и Accessibility подтверждены. 45 unit tests прошли. После удаления временного сбоя Finder snap на Retina и Undo exact за 498/408 ms, окно возвращено в исходную правую половину. Протокол до/после сохранён в Stage0Results.md. Резервная копия установки содержит обычную сборку без инъекции ошибки. Публичный релиз не менялся.
