# Текущее состояние WindowZones

Обновлено 19 сентября 2026. Этот файл описывает текущую сборку. История измерений находится в Stage0Results.md и карточках задач.

## Установленная сборка

Установлена и запущена нативная верхняя полоска раскладок. Пользователь согласовал её как основной жест после просмотра DragFlow.html. Swift 6.4, SDK 27.0, minimum macOS 15.0; текущая ОС 27.0 (26A428).

- Перетаскивание включено по умолчанию. После подтверждённого движения окна без Shift появляется подсказка в верхнем центре; при приближении раскрываются миниатюры.
- Полоска nonactivating, ignoresMouseEvents. Hit-test по глобальному курсору. Drop внутри ячейки использует общую AX-команду и сохраняет раскладку только после успешного read-back.
- Preview показывает только выбранную область без неверного номера зоны. Shift-drag и shortcut сохранены.
- Отмена Escape, отпускание Shift после его использования, смена конфигурации/Space/sleep используют существующий cancel. Drop вне ячейки ничего не размещает.
- Системные настройки и обработка краёв/углов не менялись.

Код: Sources/Geometry/DragBar.swift, Sources/WindowZones/DragBar.swift, App.swift, Interface.swift. Модель покрыта тремя новыми тестами. 45 тестов прошли, debug и release собраны, подпись проверена. Логи: .build/dragbar-tests.log, .build/dragbar-build.log, .build/dragbar-release.log.

## Текущий блокер и продолжение

После действия пользователя Accessibility подтверждён обновлением диагностики: разрешён. Нативное перетаскивание включено. Пользователю отправлена проверка Finder: задержка на заголовке 0.5 s, перенос вверх без Shift и drop над ячейкой. Пользователь подтвердил появление полоски и размещение после drop. CUA не предоставляет удержание мыши для осмотра промежуточной полоски. Показ полоски и drop подтверждены пользователем в одном прогоне, точная геометрия не измерена.

После сообщения пользователя обновить статус и проверить обычное перетаскивание Finder к верхнему центру без Shift, drop и Undo, Escape, отпускание вне ячейки, смену экрана. Проверить конфликт с системным tiling и Mission Control. Исходный capture по-прежнему отменяется, если курсор успел уйти более 3 pt до завершения AX; быстрый старт может не распознаваться. Защита сохранена ради достоверного Undo, требуется измерение.

## Подтверждения предыдущей сборки

До добавления полоски: 10 циклов Finder Retina, snap exact 586-686 ms и Undo exact 568-609 ms. Исходный frame -1216/162/920/436, target -1504/41/744/933. Tab/Shift+Tab, Escape, Enter/Space на Cancel проверены. Эти результаты не являются проверкой нового drag.

## Последние измерения предыдущей сборки

На macOS 27.0 через диагностический вход без помощи пользователя:

- Finder scale 1: snap exact 559 ms, Undo exact 376 ms.
- Finder Retina scale 2: original -1216/162/920/436, target -1504/41/744/933, actual -1504/41/744/908. Позиция точная после final correction, высота меньше на 25 pt. Undo exact 792 ms.
- Escape закрывал панель без размещения и изменения архива.
- Tab из исходного focus окна не работал. Исправление уже в новой сборке, живой повтор впереди.

Это единичные проверки, не серия из десяти циклов. Новые изменения resize ими не проверены. Более ранние результаты macOS 26.6.2 нельзя напрямую сравнивать с macOS 27.0.
