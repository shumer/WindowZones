# Предложенные пары окон

12 октября 2026. Пользователь согласовал вариант по примеру Windows Snap Layouts suggestions.

## Поведение

- Перед обычными раскладками появляется одна дополнительная пара 50/50 с иконкой соседнего приложения.
- Предпочтение получает доступное окно другого приложения, уже стоящее в одной из половин. Иначе выбирается окно недавно активного приложения, затем порядок видимых окон.
- Только видимые обычные окна того же экрана, не свёрнутые и не из исключений. История активаций ограничена 30 PID и хранится только в памяти.
- Список фиксируется при первом раскрытии панели на экране. Если поиск не успел, в этом жесте остаются обычные раскладки. Карточки не сдвигаются под курсором.
- Иконка отмечает занятую половину, отпускание доступно в свободной. Наведение подсвечивает обе будущие зоны и показывает названия приложений в панели.
- На отпускании повторно проверяются оба окна. Изменившееся соседнее окно не подменяется другим.
- Размещение последовательное. Если возникает ошибка, приложение пытается вернуть затронутые окна. AX не даёт атомарной операции для нескольких приложений.
- Общая отмена восстанавливает исходные позиции обоих окон. Неудавшиеся восстановления остаются доступными для повторной отмены.
- Смена Space, сон, отключение монитора или закрытие приложения отменяют незавершённую операцию. После отмены контекста автоматический rollback не выполняется, чтобы не двигать окна на другом рабочем столе.
- Обычный 50/50 и помощник заполнения остаются доступны отдельно. Предложенная пара не сохраняется как пользовательская раскладка.

Microsoft описывает предложения с иконками приложений и размещение нескольких окон вместе:

Точный алгоритм ранжирования Microsoft не опубликован в этих описаниях. Приоритет готовой половины и недавнего приложения является нашим решением, а не заявлением о внутренней логике Windows.

## Проверки

Локальная сборка установлена штатным install.sh с Developer ID в /Applications/WindowZones.app. Запуск и сохранённый Accessibility подтверждены на Mac. Прошли 71 автоматический тест (54 Geometry, 17 LayoutStorage) и проверка переводов. Автоматические проверки покрывают выбор кандидата, пустой список, запрет drop на иконку и доступность обычного 50/50.

Физическое размещение пары и общий Undo запрошены у пользователя, пока не подтверждены. Ошибка второго окна, частичный Undo, закрытие окна в ходе операции и смена Space требуют отдельной ручной проверки. Это локальный вариант для проверки, новый релиз не опубликован.

SDK 27.0, минимальная macOS 15, public API.
