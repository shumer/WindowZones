# 10. Первый запуск, настройки, исключения

## Реализация 7 октября 2026, после 0.2.1

Реализованы вкладки «Общие», «Управление», «Исключения», «Разрешения». Первый запуск показывает вводную; без AX команда открывает настройки, не пытаясь двигать окна. Системные prompts не вызываются при каждом запуске. Screen Recording объясняется как необязательное разрешение для миниатюр.

Сохраняются выбор между Control+Option+Space и Control+Shift+Space, модификатор Shift/Option/Control, включение drag и fill, набор исключённых bundle ID. Исключения действуют в picker, drag и fill; Undo остаётся доступен. Изменение настроек отменяет незавершённый выбор. Произвольный recorder сочетаний не добавлен.

Сохранение простых параметров использует UserDefaults с безопасными значениями по умолчанию. Это инженерное уточнение первоначального предложения JSON для всех настроек: библиотека раскладок продолжает использовать versioned JSON. Существующий fillAssistantEnabled сохранён без миграции.

На Mac проверены: установка с сохранённым AX, вкладки en/ru, добавление/удаление исключения Vivaldi и запрет picker, сохранение исключения/Option после перезапуска, Tab/Control-Tab/Space, регистрация и снятие автозапуска. Тестовые настройки возвращены к исходным. Реальный выход/вход в macOS, новый grant/revoke AX и физический drag с Option/Control не проводились. [Протокол](../SettingsAcceptance.md).


Статус: Расширенные настройки реализованы локально. Часть реальной приёмки остаётся.
Зависимости: 06, 07.

## Базовые настройки для 0.1

По новому заданию пользователя реализовано AppKit-окно: иконка, версия, SMAppService.mainApp автозапуск opt-in, Sparkle ручная/автоматическая проверка opt-in, статус Accessibility. На обычном запуске диагностика больше не открывается; настройки показываются при отсутствии разрешения. Полные onboarding, исключения и редактор shortcuts в эту правку не входят. Настройки и иконка осмотрены в опубликованной сборке. Ручная проверка и полная установка обновления через Sparkle прошли на реальном Mac. Регистрация автозапуска и настоящий login не проверены; автозапуск оставлен выключенным.
