# Правила проекта

- Общаться с пользователем на русском, просто и без корпоративного тона.
- Комментарии в коде только на английском, заканчивать точкой.
- Не использовать символы U+2013 и U+2014 в чате, документах, коде и сообщениях коммитов. Использовать обычный дефис или отдельные предложения.
- Не указывать Codex как автора или участника в сообщениях коммитов.
- Читать docs/Specification.md и документ текущего этапа до реализации.
- Различать согласованные пользователем решения, предложенные значения и фактически проверенные результаты.
- Не реализовывать весь roadmap по одному заданию на этап 0.
- Не отключать SIP, не использовать private API и не менять системный tiling без явного запроса пользователя.
- Не сохранять содержимое окон, нажатые клавиши и названия документов в логах.
- Не обрабатывать произвольные окна при запуске. Перемещать окно только по действию пользователя.
- Выполнять проверки, соответствующие изменению. Для AX и overlay нужны проверки на реальном Mac, unit tests их не заменяют.
- Недоступные ручные проверки честно отмечать как непроведённые.
- Фиксировать выбранную версию SDK и минимальную ОС. Проверять availability новых API.
- Не публиковать приложение, репозиторий или релиз от имени пользователя без соответствующего задания.
