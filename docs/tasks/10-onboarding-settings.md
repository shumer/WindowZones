# 10. Первый запуск, настройки, исключения

Статус: Очередь.
Зависимости: 06, 07.

[Очередь задач](README.md) · [Спецификация](../Specification.md)

## Результат

Заменить диагностический запуск пользовательским onboarding и настройками.

## Работа

- [ ] Объяснить Accessibility и дать путь в Settings, без бесконечного prompt.
- [ ] Без доступа разрешён редактор; при отзыве операции отключаются.
- [ ] Настраиваемые shortcuts и модификатор, исключения по bundle ID.
- [ ] Login opt-in, отключён изначально; меню для паузы/завершения и undo.

## Проверки и условие завершения

- [ ] Реальные grant/revoke и повторный запуск, конфликт shortcut, исключённое приложение.
- [ ] Настройки сохраняются, запуск не меняет чужие окна.

## Границы

Не запрашивать Input Monitoring без подтверждённой необходимости.

## Журнал и следующий шаг

Не начато.

## Базовые настройки для 0.1

По новому заданию пользователя реализовано AppKit-окно: иконка, версия, SMAppService.mainApp автозапуск opt-in, Sparkle ручная/автоматическая проверка opt-in, статус Accessibility. На обычном запуске диагностика больше не открывается; настройки показываются при отсутствии разрешения. Полные onboarding, исключения и редактор shortcuts в эту правку не входят. Реальная регистрация автозапуска и обновление ожидают проверки устанавливаемого кандидата.
