# 05. Локальное хранение и миграции

Статус: Готово, независимый модуль без подключения к приложению.
Зависимости: 04.

[Очередь задач](README.md) · [Спецификация](../Specification.md)

## Результат

Сохранять раскладки и активный выбор локально с версией схемы.

## Работа

- [x] Codable JSON, путь Application Support, атомарная запись, последняя валидная копия. Запись в реальный профиль пока не подключена.
- [x] Встроенные шаблоны при первом load без записи и перезаписи пользовательских данных.
- [x] Импорт/экспорт Data с лимитом 1 MB, валидатором, проверкой UUID и версии.
- [x] Чистая операция смены active layout только после успешного размещения; draft хранится отдельно от сохранённой коллекции. Подключение результата AX относится к 06.

## Проверки и условие завершения

- [x] Round-trip, повреждённый файл, новая неизвестная версия, дубликаты UUID и оставшийся недописанный temp проверены. Реальный сбой питания не имитировался.
- [x] Импорт и инициализация store не двигают чужие окна; тесты работают в отдельных временных папках.

## Границы

Без облака и синхронизации.

## Журнал и следующий шаг

Чистое ядро 04 прошло проверки. Реализуются LayoutCollection, versioned LayoutArchive и сериализованный actor LayoutStore. Тесты используют только собственные временные папки. Реальная Application Support и app bundle не изменяются.

Итог: Sources/LayoutStorage/LayoutArchive.swift и LayoutStore.swift; Tests/LayoutStorageTests/LayoutStorageTests.swift. Отдельный агент написал тесты по контракту, другой выполнил read-only ревью. Найденная ошибка перезаписи backup более новой схемы исправлена и покрыта регрессией.

Все 42 теста проекта прошли, включая 13 хранения. Реальное приложение не подключено к модулю, его release bundle не пересобирался в задачах 04-05. Контракт и ограничения: [LayoutStorage.md](../LayoutStorage.md).

Следующая задача 06 требует незавершённых UX 02 и технической проверки 03. Их готовность не подменяется тестами ядра. В частности, чтобы продолжить реальные проверки 03, требуется завершить системную аутентификацию Accessibility.
