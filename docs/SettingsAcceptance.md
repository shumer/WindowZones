# Настройки, доступность и распространение

Дата: 7 октября 2026. Локальная сборка после публичной 0.2.1, arm64, SDK 27.0, минимум macOS 15. CI остаётся на Xcode 26.6/SDK 26.5. Редактор раскладок не входит в эту работу.

## Сделано

- Четыре нативные вкладки настроек, вводная на первом запуске, статусы AX и записи экрана.
- Два пресета shortcut, Shift/Option/Control для drag, постоянная пауза drag, fill opt-out.
- Исключения через выбор .app, хранение bundle ID, применение в трёх сценариях.
- 161 ключ основных пользовательских поверхностей en/ru, переводы упакованы в .app. Пользовательские названия не изменяются.
- Tab/Shift-Tab и Control-Tab в настройках, фокус карточек и кнопок помощника, контраст/непрозрачность карточек.
- Проверка каталогов включена в scripts/test.sh и тем самым в CI. scripts/verify-update.swift проверяет подпись и негативные варианты архива.

Для проверки ошибки сети запускали установленное приложение с аргументом `-SUFeedURL https://windowzones-update-test.invalid/appcast.xml`. Это аргумент одного запуска, не изменение Info.plist или сохранённого feed. После проверки нужно оставлять обычный запуск без него.

Проверка EdDSA не подменяет тест плохого архива через весь Sparkle installer. Регистрация login item не подменяет настоящий выход и вход в macOS. AX-дерево не подменяет прослушивание VoiceOver.
