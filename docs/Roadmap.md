# План разработки

Текущая последовательная очередь и статусы: [tasks/README.md](tasks/README.md). Таблица ниже показывает крупные этапы, а не заменяет карточки задач. Выбранное направление UX: A + C, B необязателен. Версия спецификации 0.2 не означает завершение технического этапа 0.

| Этап | Работа | Условие перехода |
|---|---|---|
| 0. Feasibility | AX, 3 зоны, команды, undo, drag experiment | Отчёт реальных проверок, понятные ограничения |
| 1. UX и ядро зон | 2-3 варианта editor/overlay, split tree, persistence, профили экранов | Выбран UX, проверены геометрия и сохранение |
| 2. Личная alpha | Редактор, drag snapping, picker, shortcuts, исключения, настройки | Основной рабочий набор приложений стабилен |
| 3. Закрытая beta | Onboarding, import/export, en/ru, accessibility, reconnect, диагностика | 3-5 внешних пользователей, исправлены блокирующие ошибки |
| 4. Публичный выпуск | Бренд, иконка, signing, notarization, updates, документация | Чистая установка и upgrade проверены, известные ограничения опубликованы |

Каждый результат имеет отдельную MD-карточку и критерии завершения. Отдельные задачи в интерфейсе приложения создавать только по явному запросу. Не поручать независимым агентам одновременно менять одну область кода.

Даты пока не назначены. Оценку дать после этапа 0 с учётом реальной совместимости. Apple Developer account и модель распространения не блокируют прототип, но нужны к публичному выпуску.
