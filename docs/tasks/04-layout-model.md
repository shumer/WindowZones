## Результат

Подготовить чистую модель Layout с деревом разделителей для последующей замены фиксированных зон. Текущий AX-прототип пока использует прежний расчёт.

## Работа

- [x] Leaf UUID/name; split axis/ratio/children; стабильная нумерация зон.
- [x] Четыре стартовых шаблона из согласованной концепции.
- [x] Пределы глубины, 1-12 зон, finite ratios, gap/inset и минимальные эффективные размеры.
- [x] Общие границы и округление по scale; геометрия без AppKit/AX.

## Проверки и условие завершения

- [x] Тесты сохраняют площадь с gap, не дают перекрытий и проверяют вложенные splits.
- [x] Проверены отрицательные координаты, разные scale, слишком маленький экран и невалидные деревья.

## Границы

Не подключать UI или перемещение окон до проверки геометрии.

## Журнал и следующий шаг

Начата после поручения пользователя продолжать доступную работу без Accessibility. Модель и геометрия не требуют разрешения на управление окнами. Независимый субагент готовит регрессионные тесты по контракту API, реализация выполняется отдельно.

Результат: Sources/Geometry/Layout.swift и BuiltInLayouts.swift, независимые LayoutGeometryTests и отдельные BuiltInLayoutsTests. Все 29 тестов проекта прошли после добавления 14 тестов нового ядра. Прежняя функция GeometryEngine.zones и её использование прототипом не изменены.

Ревью выявило искажение глобальных долей последовательными gap. Исправлено общей семантикой бюджета промежутков, без проверки специальных UUID в resolver. Контроль 1440 pt / inset8 / gap8 / scale2 даёт 352/704/352 pt. Равные трети отличаются не больше одного backing pixel. Проверены gap 0/8/32 и scale 1/1.25/1.5/2.

Важное следствие для 08: ratio означает долю полезной протяжённости без промежутков, а не положение разделителя в процентах полного прямоугольника. Добавление дочернего split может слегка сдвинуть родительскую границу, сохраняя полезные доли. Редактор должен преобразовывать положение мыши с учётом gapBudget и явно называть числовое поле. Нельзя привязать drag divider к raw width * ratio.

Следующий шаг: 05, локальный архив и хранилище. AX, темы и нативный UI этим результатом не проверены. Контракт: [LayoutModel.md](../LayoutModel.md).
