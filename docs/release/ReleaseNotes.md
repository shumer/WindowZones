# WindowZones 0.3.1

Clearer settings and a cleaner everyday experience.

- Settings now group options into cards, with a compact app header, clear explanations and visible permission status.
- Excluded apps show their names and icons instead of bundle identifiers. Empty lists explain that no apps have been excluded.
- The development diagnostics window is no longer part of the normal menu and no longer opens after a regular window-selection error.
- Settings keep the existing preferences and support keyboard navigation between sections.

68 automated tests passed locally. All four settings sections and Control-Tab navigation were checked on the test Mac, and the user accepted the redesign. Full VoiceOver, dark-mode acceptance and fresh permission grants remain unverified for this change.

Apple silicon, macOS 15 or later. Developer ID signed and notarized by Apple. Existing early-release limitations still apply, including app minimum window sizes and incomplete portrait/mixed-display and lifecycle testing.

Use Check for Updates in WindowZones, or download WindowZones-0.3.1-arm64.zip.

Report issues at https://github.com/shumer/WindowZones/issues. Remove private content from screenshots.
