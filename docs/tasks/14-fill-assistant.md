# 14. Помощник заполнения раскладки

Статус: реализованы доработки 1-3, выполнены доступные проверки пункта 4. Ограничения приёмки указаны ниже. Запрошен пользователем 7 октября 2026, перед редактором.

После успешного размещения первого окна предложить другие открытые окна для оставшихся зон выбранной раскладки на том же экране. Выбор каждого окна явный. Использованные окна исключаются. Зону можно сменить, пропустить, закончить через Escape. Undo отменяет последнее размещение и закрывает помощник. Уже размещённые окна остаются при отмене.

Список содержит обычные доступные окна на текущем экране. Свёрнутые, fullscreen, собственные окна и недоступные AX-цели исключаются. Цель сохраняется отдельным AX reference, проверяется перед записью. Занятые точно совпадающим окном зоны пропускаются. Новые раскладки и редактор не входят.

Миниатюры через ScreenCaptureKit только при уже выданном разрешении. Без доступа карточка показывает иконку и название окна. Запрос разрешения только отдельной кнопкой пользователя. Картинки и названия не пишутся на диск или в диагностику. Не сопоставлять превью неоднозначных окон по одному PID.

Проверки: модель переходов, skip/selection/completion; реальное размещение, второй выбор, Escape, Undo, отсутствие доступа к превью; отмена сессии при Space/sleep/смене экрана. Отдельно отметить непроведённое.


## Реализация и проверка

Нативная панель показывает карту раскладки, следующую зону, карточки окон, Пропустить, Обновить, Undo и Готово. Неизменённые занятые зоны пропускаются при начале сессии. Обновление списка не сбрасывает выбранную зону. Смена конфигурации экрана, Space и sleep закрывают сессию через общий cancellation. Список ограничен доступными обычными окнами текущего экрана и onscreen metadata; окна других Spaces не подтягиваются.

Перед выбором повторно читается frame конкретного AX reference, чтобы Undo использовал актуальное исходное положение. При adjusted действует политика небольших отклонений, описанная ниже. Проверка состояния выполняется самим AX pipeline. Миниатюра сопоставляется только при единственном совпадении PID и frame; неоднозначные варианты остаются с иконкой. Снимки только в памяти, задачи отменяются при закрытии/обновлении.

На Mac без разрешения Screen Recording проверены появление после первой четверти Finder, выбор Lifecycle Probe во вторую четверть, переход к третьей, исключение использованного окна, смена зоны, пропуск, Undo. Fixture snap exact 803 ms, Undo exact 822 ms. Оригинал (150,558,900,682), вторая четверть (1284,38,1268,649). Визуально проверена панель с иконками. Наблюдалась отмена при изменении visibleFrame с 87 до 89 pt, что соответствует текущей общей политике конфигурации.

55 unit tests (14 storage, 41 geometry) прошли. SDK 27.0, minimum macOS 15, arm64. Установка только через install.sh --diagnostics. Нового релиза нет.

На момент первого варианта были непроведены: миниатюры, длинный список, VoiceOver и полная матрица мониторов/Spaces. Обновлённые результаты ниже. Эти результаты не засчитываются по компиляции.

Превью сценария: [FillAssistant.html](../design/FillAssistant.html). Панель приложения является нативным первым вариантом; HTML иллюстрирует заполнение зон, а не пиксельную копию панели.

Финальная сборка: Escape проверен через UI на открытом помощнике, панель закрылась без дополнительного Snap. Fixture первоначально размещена exact 825 ms в (8,38,1268,651). Пропущенная зона обозначается отдельно от занятой; adjusted не продвигает сессию.


7 октября, проверка после выдачи пользователем Screen Recording: запущен executable /Applications/WindowZones.app/Contents/MacOS/WindowZones. После размещения собственного Lifecycle Probe открылся помощник. Кнопка запроса разрешения отсутствует, в карточке другого окна видна настоящая миниатюра. Проверено визуально через UI, снимок не сохранялся в файлы проекта. Через Undo возвращено тестовое окно; чужое окно из карточки не выбиралось и не перемещалось. Это один успешный реальный захват, не вся матрица нескольких окон/экранов.

В диагностике пользовательских операций Terminal перед проверкой три adjusted, последние expected 1268x652 и actual 1267x662. По текущему коду помощник после такого результата не стартует: требуется близость actual к target с допуском 2 pt. Это отдельное UX-ограничение запуска, не отказ Screen Recording. Требует отдельного решения о допустимом отклонении и пересечении соседних зон.


## Доработки 1-4, 7 октября 2026

1. Небольшой adjusted принимается при отклонении каждой границы не более 16 pt. Это выбранная техническая политика, не ранее согласованное пользователем число. Реальный frame резервирует все зоны, которые перекрывает больше чем на 1 pt по обеим осям. Такие зоны отмечены галочкой и не предлагаются. Большое отклонение не засчитывается, доступен Undo. Для Terminal с +10 pt высоты соседняя четверть может оказаться недоступной. Автоматического уменьшения соседних зон нет.
2. Список автоматически обновляется раз в 2 секунды без активации панели. Идентичность окна сохраняется через AX reference. Закрытые, свёрнутые и ушедшие с экрана окна исключаются, освобождённые зоны возвращаются. Явно пропущенные зоны не возвращаются. Чтение каждого окна имеет отдельный лимит, общий обход ограничен 3 секундами. Изменения появляются после завершения обхода, не мгновенно. Неответившее AX-окно может временно исчезнуть до следующего обхода.
3. Карточки 328x172, две колонки, прокрутка, пропорциональные миниатюры. Выбранная зона выделена синей рамкой. Стрелки перемещают фокус и прокручивают список, Enter/Space выбирают окно, Escape завершает. Ошибка размещения сохраняется при фоновом обновлении.
4. Проверка на установленной Developer ID сборке из /Applications. Отдельное тестовое приложение в этом проходе не запускалось. Уже работавшая старая fixture попадала в список, но не выбиралась.

### Результаты на Mac

- Четверти на основном экране: Finder в зоне 1 exact 947 ms, второе окно Finder в зоне 3 exact 949 ms, третье в зоне 4 exact 1032 ms. Зона 2 была занята до теста и пропущена. После заполнения последней свободной зоны помощник закрылся.
- Новое окно Finder появилось автоматически. Закрытие окна освободило занятую зону и сохранило выбор другой зоны. Закрытая карточка исчезла. Свёрнутая карточка исключена; обнаруженный общий короткий AX deadline заменён отдельным лимитом для каждого окна.
- Проверены длинный список из 9 карточек, прокрутка стрелками, сохранение фокуса после удаления соседней карточки, Escape, реальные миниатюры и fallback на иконки при неоднозначном сопоставлении одинаковых frames.
- Retina: Finder exact 597 ms, target (-1504,41,744,933). Помощник показывает кандидатов второго экрана и настоящую миниатюру. Enter выбрал Discord. Discord потребовал ширину 800 вместо 744, adjusted 1057 ms, сессия не завершилась как успешная. Undo exact 795 ms восстановил (-1512,33,1512,884).
- 57 тестов: 14 storage, 43 geometry. Добавлены проверки сохранения выбора/пропуска при изменении занятости и округления Terminal с пересечением соседней зоны. Release build, подпись и установка прошли. SDK 27.0, минимум macOS 15, arm64.

### Честные границы приёмки

Новый запуск именно Terminal после малого adjusted не проверен физически: его frames проверены модельным тестом. Управление Terminal инструментом недоступно. Отсутствие Screen Recording проверялось в предыдущем проходе; выданное пользователем разрешение в этом проходе не отзывалось. VoiceOver, полная матрица Spaces и отключение физического монитора не проверены. Нельзя считать эти сценарии пройденными по unit tests. Нового релиза или публикации нет.


### Исправление видимости помощника после Terminal

После сообщения пользователя о невидимом помощнике инструмент обнаружил уже созданную панель с выбранной левой половиной и тремя карточками. Следовательно, для наблюдавшейся сессии запуск и перечисление окон состоялись. Почему пользователь не видел панель, однозначно не установлено: прежняя панель имела обычный уровень и стандартное центрирование без привязки к целевому экрану.

Исправлено представление: floating level, hidesOnDeactivate=false, явный показ поверх обычных окон. Панель центрируется относительно выбранной свободной зоны и ограничивается visibleFrame целевого дисплея. Фоновое обновление списка по-прежнему не активирует приложение. Добавлены тесты геометрии для правого внешнего дисплея и Retina с отрицательным X. Это изменение показа, не увеличение допуска AX и не новое разрешение Screen Recording.

Проверка исправления: 59 тестов прошли (14 storage, 45 geometry). Установка и подпись проверены. На Finder правая половина exact 546 ms, помощник открылся с выбранной левой зоной и настоящими миниатюрами. Undo exact 535 ms вернул исходную нижнюю правую четверть. Физический drag Terminal после этой правки не повторялся.
