## Что осталось до полной приёмки

1. Локализовать отсутствие focused window в Chrome. Не подбирать произвольное окно из AXWindows и не включать private accessibility attributes.
2. Закрепить повторную матрицу Finder/Terminal и ложных drag с числом попыток. Terminal не управляется инструментом; нужна проверка человеком.
3. Отдельно проверить сон, отзыв Accessibility и reconnect на реальном Mac. Не отключать пользовательские разрешения без согласованной тестовой сессии.
4. После этого принять решение о закрытии 03. Редактор и новый релиз не являются способом обойти незавершённую приёмку.

Полные frames, версии, время и различия между версиями находятся в [Stage0Results.md](Stage0Results.md). Установленная сборка обычная, без временной инъекции ошибки.
